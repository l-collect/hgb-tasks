# 护肝宝任务包

[护肝宝](https://github.com/lc-cn/hgb) 的任务包放在这里。每个任务版本是这个仓库的一次 GitHub 发布（Release），发布里带一个任务包文件；护肝宝 App 读取这里最新的正式发布，下载并校验后启用。

- 代码和 App 在 [lc-cn/hgb](https://github.com/lc-cn/hgb)，那里的发布只放 App 安装包。
- 任务包的格式和怎么写任务，见文档站的[任务包说明](https://hgb.l2cl.link/docs/dev/task-bundles/)。
- 发布任务需要这个仓库的写权限，和代码仓库分开。
